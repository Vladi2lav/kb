# Kanban

Канбан-доски с паролями. Любой может создать свою доску, открыть её по ссылке и паролю с любого устройства, поделиться ссылкой.

Без сборки и npm-зависимостей: чистые HTML/CSS/JS + маленький Node-сервер.

## Возможности
- Доски с паролем; сессия в браузере живёт 30 дней, список «Мои доски» на главной.
- Свои колонки: добавить, переименовать (двойной клик), сдвинуть, удалить.
- Карточки: многострочный текст, ссылки кликабельны, цветные метки, редактирование по двойному клику или ✎, удаление с «Отменить».
- Drag & drop мышью и пальцем (на телефоне — долгое нажатие).
- Поиск по карточкам (клавиша `/`).
- Совместная работа: доска обновляется раз в 5 с, одновременные правки сливаются.
- Настройки доски: название, смена пароля (старые сессии сбрасываются), удаление.
- Экспорт и импорт JSON.

## Защита от ботов
Создание доски:
- proof-of-work: браузер ~1 с подбирает хэш (`POW_BITS`, по умолчанию 18), скриптам массово это дорого;
- одноразовый челлендж живёт 15 минут, форму нельзя отправить быстрее чем за 3 с;
- скрытое поле-ловушка (honeypot);
- лимиты: 3 доски в час и 10 в сутки с одного IP, 300 в сутки всего (`MAX_BOARDS_PER_DAY`).

Вход: после 10 неверных паролей с IP или 30 на одну доску вход блокируется на 15 минут. Пароли хранятся как scrypt-хэши.

## Локально
```bash
npm start
```
Открой http://localhost:3000. Данные лежат в `data/db.json`.

## Render
1. Тип сервиса — **Web Service** (не Static Site), Runtime: Node, Build Command: `npm install`, Start Command: `npm start`.
2. Файловая система Render стирается при каждом деплое, поэтому данные храни вне её: создай бесплатную базу на upstash.com и добавь переменные `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`. Другой вариант — подключить Persistent Disk (платно) и задать `DATA_DIR` равным пути к нему.
3. Задай `APP_SECRET` (длинная случайная строка) — им подписываются сессии.

## Vercel
1. Импортируй проект, Framework Preset: **Other** (если в репозитории проект лежит в подпапке — укажи её в Root Directory).
2. Storage → подключи **Upstash Redis** (появятся `KV_REST_API_URL` и `KV_REST_API_TOKEN`).
3. Желательно задать `APP_SECRET` (длинная случайная строка) — им подписываются сессии.

## Старая доска
Доска из прошлой версии сохранена как «Моя доска» (`lib/seed.js`). При первом открытии в браузере, где лежала старая доска, карточки перенесутся автоматически.
Если открываешь `index.html` как файл, страница предложит скачать старую доску в JSON — потом загрузи её через ⋯ → «Импорт из JSON».
