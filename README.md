# Kanban

Простейшая канбан-доска: три колонки, drag & drop, редактирование по двойному клику, данные в `localStorage`.

Без сборки и зависимостей — чистые HTML/CSS/JS.

## Локально
Просто открой `index.html` в браузере.

## Деплой на Vercel
Импортируй репозиторий на vercel.com → Framework Preset: **Other** → Deploy. Build command не нужен.
